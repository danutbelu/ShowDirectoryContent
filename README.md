# ShowDirectoryContent
A lightweight .NET console application that lists all files and subdirectories from a specified directory path provided as a command-line argument.

# Description
This project is a simple and efficient .NET console application designed to display the contents of a directory, including both files and subdirectories. The application accepts a single command-line parameter representing the target directory path and outputs the directory structure directly in the console.

It can be used for quick directory inspection, scripting, automation tasks, or as a starting point for learning file system operations in .NET.

Features
Lists files and subdirectories
Accepts directory path as a command-line argument
Simple and lightweight implementation
Built with .NET
Easy to extend with additional functionality
